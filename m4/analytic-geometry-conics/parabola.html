พาราโบลา

ภาคตัดกรวยที่ระนาบเอียงขนานกับเส้นรอบรูปกรวยพอดี

🔺ภาคตัดกรวยคืออะไร

ภาคตัดกรวย (Conic Section) คือเส้นโค้งที่เกิดจากการใช้ระนาบตัดกรวยกลม 2 กรวยที่ต่อกันที่จุดยอด รูปร่างของเส้นโค้งที่ได้ขึ้นอยู่กับมุมเอียงของระนาบเทียบกับแกนกรวยเพียงอย่างเดียว — ถ้าระนาบเอียงจนขนานกับเส้นรอบรูป (เส้นบนผิวกรวย) ของกรวยพอดี จะได้ พาราโบลา ซึ่งเป็นเส้นโค้งเปิดไม่มีที่สิ้นสุด

เลือกชนิดด้านบน แล้วลากจุด O, A, B บนภาพ (หรือแถบเลื่อนด้านล่าง) เพื่อปรับระนาบสีฟ้า สังเกตว่าเส้นโค้งสีส้มที่ระนาบตัดกรวยเปลี่ยนไปอย่างไร — ลากที่ว่างบนภาพเพื่อหมุนมุมมองดูได้

ลากจุด O · A · B บนภาพเพื่อปรับระนาบ · ลากที่ว่างเพื่อหมุนมุมมอง 3 มิติ

ซูม
📐นิยามพาราโบลา

พาราโบลา (Parabola) คือเซตของจุดทุกจุดบนระนาบ ซึ่งมีระยะห่างจากจุดคงที่จุดหนึ่ง (เรียกว่า โฟกัส, focus) เท่ากับระยะห่างจากเส้นตรงคงที่เส้นหนึ่ง (เรียกว่า เส้นไดเรกตริกซ์, directrix) เสมอ — จุดกึ่งกลางระหว่างโฟกัสกับไดเรกตริกซ์ เรียกว่า จุดยอด (vertex)

(x−h)² = 4c(y−k)

สมการรูปแบบมาตรฐาน เมื่อจุดยอดอยู่ที่ (h,k) แกนสมมาตรตั้งฉากกับแกน x (เปิดขึ้นถ้า c>0 เปิดลงถ้า c<0) — สลับ x กับ y เพื่อได้กรณีแกนสมมาตรขนานแกน x

ระยะห่างจากจุด P ถึงโฟกัส เท่ากับระยะห่างจากจุด P ถึงเส้นไดเรกตริกซ์เสมอ
🎯องค์ประกอบของพาราโบลา
(x−0)² = 4(2)(y−0)
ซูม

ลากจุดยอด V หรือจุดโฟกัส F (F เลื่อนได้เฉพาะตามแนวแกนสมมาตร) — หรือจะพิมพ์พิกัดด้านล่างก็ได้

✍️พิสูจน์สมการพาราโบลา

นิยามพาราโบลา: ทุกจุดบนพาราโบลาห่างจากโฟกัส เท่ากับ ห่างจากเส้นไดเรกตริกซ์ — เราจะเขียนระยะทั้งสองเป็นสูตรแล้วจับให้เท่ากัน

ก. แกนสมมาตรแนวตั้ง จุดยอดที่จุดกำเนิด
1
ให้จุดยอดอยู่ที่จุดกำเนิด โฟกัสอยู่ที่ F(0, c) บนแกน y แกนสมมาตรจึงอยู่ในแนวตั้ง และไดเรกตริกซ์คือเส้น y = −c ให้ P(x, y) เป็นจุดใดๆ บนพาราโบลา
2
ระยะจาก P ถึงโฟกัส F ใช้สูตรระยะห่างระหว่างจุด
PF=(x − 0)² + (y − c)² = x² + (y − c)²
3
ระยะจาก P ถึงไดเรกตริกซ์ y = −c คือระยะในแนวตั้ง (ลากตั้งฉากลงไปที่เส้น)
PD=|y − (−c)| = |y + c|
4
จากบทนิยามของพาราโบลา PF = PD
x² + (y − c)²=|y + c|
5
ยกกำลังสองทั้งสองข้าง (ทั้งสองข้างไม่ติดลบ) — กำลังสองของค่าสัมบูรณ์เท่ากับกำลังสองของตัวข้างใน
x² + (y − c)²=|y + c|² = (y + c)²
6
กระจายกำลังสอง
x² + y² − 2cy + c²=y² + 2cy + c²
7
ตัด y² และ c² ที่มีทั้งสองข้าง แล้วย้าย −2cy ไปฝั่งขวา
x²=4cy
รูปแบบมาตรฐาน (จุดยอดที่จุดกำเนิด แกนสมมาตรแนวตั้ง)x² = 4cy
c > 0 พาราโบลาหงาย · c < 0 พาราโบลาคว่ำ
8
ถ้าเลื่อนจุดยอดจาก (0, 0) ไปที่ (h, k) ให้แทน x ด้วย x − h และแทน y ด้วย y − k
(x − h)²=4c(y − k)
รูปแบบมาตรฐาน แกนสมมาตรแนวตั้ง(x − h)² = 4c(y − k)
ข. แกนสมมาตรแนวนอน
9
ถ้าโฟกัสอยู่ที่ F(c, 0) บนแกน x แกนสมมาตรอยู่ในแนวนอน และไดเรกตริกซ์คือเส้น x = −c ทำขั้นที่ 2–7 ซ้ำโดยสลับบทบาท x กับ y
(x − c)² + y²=|x + c|y²=4cx
รูปแบบมาตรฐาน แกนสมมาตรแนวนอน (จุดยอด (h, k))(y − k)² = 4c(x − h)
c > 0 เปิดไปทางขวา · c < 0 เปิดไปทางซ้าย
ค. ลาตัสเรกตัม
10
ลาตัสเรกตัมคือคอร์ดที่ผ่านโฟกัสและตั้งฉากกับแกนสมมาตร แทน y = c ใน x² = 4cy จะได้ x² = 4c² ดังนั้น x = −2c หรือ x = 2c
ความยาวลาตัสเรกตัม=|2c − (−2c)| = |4c|
ยิ่ง |4c| มาก พาราโบลายิ่งกว้าง
ง. สมการรูปแบบทั่วไป
11
แกนสมมาตรแนวตั้ง: กระจาย (x − h)² = 4c(y − k) แล้วย้ายค่าคงตัวไปขวา
x² − 2hx + h²=4cy − 4ckx² − 2hx − 4cy=−h² − 4ck
แทน D = −2h, E = −4c, F = −h² − 4ckx² + Dx + Ey = F
ไม่มีพจน์ y² (เขียนแบบครูได้ว่า x² + 0y² + Dx + Ey = F)
12
แกนสมมาตรแนวนอน: กระจาย (y − k)² = 4c(x − h) แล้วย้ายค่าคงตัวไปขวา
y² − 2ky + k²=4cx − 4chy² − 4cx − 2ky=−k² − 4ch
แทน D = −4c (สัมประสิทธิ์ของ x), E = −2k (สัมประสิทธิ์ของ y), F = −k² − 4chy² + Dx + Ey = F
ไม่มีพจน์ x² (y² + 0x² + Dx + Ey = F)
