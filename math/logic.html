🔤ประพจน์คืออะไร

ประพจน์ (proposition) คือประโยคที่บอกได้แน่นอนว่า จริง (T) หรือ เท็จ (F) อย่างใดอย่างหนึ่งเท่านั้น

ประพจน์ — 3 + 2 = 5 (จริงแน่นอน ไม่ต้องแทนอะไรเพิ่ม)
ไม่ใช่ประพจน์ — x + 2 = 3 เรียกว่า ประโยคเปิด (open sentence) เพราะยังต้องแทนค่า x ก่อนถึงจะรู้ว่าจริงหรือเท็จ
⚠️ คำสั่ง คำถาม คำอุทาน (เช่น "ปิดประตูด้วย", "กี่โมงแล้ว") ไม่ใช่ประพจน์ เพราะบอกจริง/เท็จไม่ได้

A proposition is a sentence that is definitely either true (T) or false (F) — never both, never neither.

Proposition — 3 + 2 = 5 (definitely true, nothing left to substitute)
Not a proposition — x + 2 = 3 is an open sentence: you must substitute a value for x before it has a truth value.
⚠️ Commands, questions and exclamations ("Close the door", "What time is it?") are not propositions — they cannot be true or false.
🔗ตัวเชื่อม 5 ตัว
ตัวเชื่อม อ่านว่า จำสั้นๆ
∧ และ เป็นจริงตัวเดียว คือ T ∧ T ≡ T นอกนั้นเท็จหมดTrue only when T ∧ T; otherwise false
∨ หรือ เป็นเท็จตัวเดียว คือ F ∨ F ≡ F นอกนั้นจริงหมดFalse only when F ∨ F; otherwise true
→ ถ้า...แล้ว เป็นเท็จตัวเดียว คือ T → F ≡ F นอกนั้นจริงหมดFalse only when T → F; otherwise true
↔ ก็ต่อเมื่อ เหมือนกัน = จริง, ต่างกัน = เท็จSame = true, different = false
~ นิเสธ (ไม่) ตรงข้ามเสมอ — ~T ≡ FAlways the opposite — ~T ≡ F

pq~pp ∧ qp ∨ qp → qp ↔ q

Order of operations: ~ first → then ∧ → then ∨ → then → → finally ↔  (use parentheses to override).
🧮วิธีหาค่าความจริง 2 แบบ
1
ใช้แผนภาพ — ใช้เมื่อ รู้ค่าความจริงของแต่ละตัวแปรแล้ว เขียนค่าไว้ใต้ตัวแปร แล้วไล่รวมทีละตัวเชื่อมจนถึงตัวสุดท้าย
เช่น ถ้า p ≡ T, q ≡ F, r ≡ T แล้ว (p ∧ q) → r จะได้ F → T ≡ T
2
ใช้ตาราง — ใช้เมื่อ ไม่รู้ค่าตัวแปร ต้องแจกแจงทุกกรณี (n ตัวแปร ได้ 2ⁿ แถว) แล้วค่อยๆ คิดทีละคอลัมน์จากวงเล็บในสุดออกมา
เครื่องมือด้านล่างทำแบบที่ 2 ให้อัตโนมัติ
1
Value diagram — use it when each variable's truth value is already known: write the values under the variables and combine one connective at a time.
e.g. with p ≡ T, q ≡ F, r ≡ T, the formula (p ∧ q) → r gives F → T ≡ T
2
Truth table — use it when the values are unknown: list every case (n variables → 2ⁿ rows), then fill one column at a time from the innermost bracket outwards.
The tool below does method 2 automatically.
⚡ตัวสร้างตารางค่าความจริง

พิมพ์ประพจน์ที่ต้องการ (ตัวแปรได้สูงสุด 3 ตัว เช่น p, q, r) กดปุ่มสัญลักษณ์ด้านล่างเพื่อแทรกตัวเชื่อม

ตัวอย่าง: p ∧ q → r ~(p ∨ q) (p → q) ↔ (~p ∨ q)
ลำดับการเปิด: คอลัมน์ตัวแปร (p, q, r) เปิดทีเดียวทั้งคอลัมน์ → คอลัมน์ที่มีตัวเชื่อมเปิดทีละช่องจากบนลงล่าง
📜สมบัติของตรรกศาสตร์ 23 ข้อ

ตารางอ้างอิงนี้คือ "อาวุธ" ที่ใช้ในแท็บ สมมูล — ทุกขั้นตอนที่เครื่องมือแสดง จะอ้างอิงหมายเลขข้อจากตารางนี้เสมอ

This reference table is the toolkit used in the Equivalence tab — every step the tool shows cites a numbered law from this table.

⚠️ ข้อควรระวัง: p → q ไม่สมมูลกับ q → p — ตัวเชื่อม → สลับที่ไม่ได้ (ต่างจาก ∧ ∨ ↔ ที่สลับได้)
⚠️ Watch out: p → q is not equivalent to q → p — implication is not commutative (unlike ∧ ∨ ↔).
🔑ปอกทริก — สมมูล

สมมูล (≡) คือสองประพจน์ที่มีค่าความจริง ตรงกันทุกกรณี — วิธีพิสูจน์ที่ครูใช้คือแปลงข้างหนึ่งด้วย สมบัติ 23 ข้อ ให้กลายเป็นอีกข้างหนึ่ง

1
เลือกทำ ข้างซ้ายไปขวา หรือ ขวาไปซ้าย ก็ได้ — ปกติเริ่มจากข้างที่ ซับซ้อนกว่า
2
ใช้ สมบัติที่ตรงกับรูปที่เห็น แปลงไปเรื่อยๆ ทีละข้อ (ดูตารางในแท็บสมบัติ 23 ข้อ)
3
เหมือน = สมมูล  |  ไม่เหมือน = ไม่สมมูล
💡 ที่เจอบ่อยที่สุดคือข้อ 2 (p → q ≡ ~p ∨ q) และข้อ 5 (De Morgan) — เจอ → ให้นึกถึงข้อ 2 ก่อนเสมอ

Equivalence (≡) means two propositions have the same truth value in every case. The classroom method: rewrite one side into the other using the 23 laws.

1
Work left → right or right → left, whichever you like — normally start from the more complicated side.
2
Apply whichever law matches the shape you see, one step at a time (see the 23-laws tab).
3
Same = equivalent  |  Different = not equivalent
💡 The two you will use most are law 2 (p → q ≡ ~p ∨ q) and law 5 (De Morgan) — whenever you see →, think of law 2 first.
🟰ตรวจสอบสมมูลจากประพจน์ของคุณเอง
ตัวอย่าง: p → q  ≡  ~p ∨ q ~(p ∨ q)  ≡  ~p ∧ ~q p ∨ (p ∧ q)  ≡  p p → q  ≟  q → p
🔑ปอกทริก — สัจนิรันดร์

สัจนิรันดร์ (tautology) คือประพจน์ที่เป็น จริงทุกกรณี — แทนที่จะแจกแจงตารางทั้ง 2ⁿ แถว ให้ใช้ทริก "สมมติว่าเป็นเท็จแล้วหาข้อขัดแย้ง"

1
สมมติ ให้ประพจน์ทั้งก้อนเป็น F
2
ไล่ค่าไปเรื่อยๆ ตามกฎของตัวเชื่อม (เช่น A → B ≡ F บังคับให้ A ≡ T และ B ≡ F)
3
ถ้าไล่แล้ว ขัดแย้ง (ตัวแปรตัวเดียวต้องเป็นทั้ง T และ F) → เป็นสัจนิรันดร์
4
ถ้า ไม่ขัดแย้ง = มีทางทำให้เป็นเท็จได้ → ไม่เป็นสัจนิรันดร์
💡 ถ้าเจอกิ่งที่แยกได้หลายทาง (เช่น A ∧ B ≡ F ได้ทั้ง A ≡ F หรือ B ≡ F) ต้อง คิดแยกทุกกิ่ง — จะเป็นสัจนิรันดร์ก็ต่อเมื่อ ขัดแย้งทุกกิ่ง

A tautology is a proposition that is true in every case. Instead of writing out all 2ⁿ rows, use the trick "assume it is false and look for a contradiction".

1
Assume the whole proposition is F.
2
Propagate forced values through the connectives (e.g. A → B ≡ F forces A ≡ T and B ≡ F).
3
If you reach a contradiction (one variable forced to be both T and F) → it is a tautology.
4
If no contradiction, you found a way to make it false → not a tautology.
💡 When a step splits (e.g. A ∧ B ≡ F allows either A ≡ F or B ≡ F) you must follow every branch — it is a tautology only if every branch contradicts.
♾️ตรวจสอบสัจนิรันดร์จากประพจน์ของคุณเอง
ตัวอย่าง: (p ∧ q) → p p ∨ ~p (p → q) → (q → p) ((p → q) ∧ p) → q
🔑ปอกทริก — สมเหตุสมผล

การอ้างเหตุผล สมเหตุสมผล (valid) เมื่อ "ถ้าเหตุทุกข้อจริง แล้วผลต้องจริงตาม" — ทริกคือแปลงให้เป็นโจทย์สัจนิรันดร์แล้วใช้วิธีเดิม

1
เชื่อมเหตุทุกข้อด้วย ∧ แล้วเชื่อมไปหาผลสรุปด้วย →  →  (เหตุ₁ ∧ เหตุ₂ ∧ ...) → ผลสรุป
2
หาว่าเป็นสัจนิรันดร์หรือไม่ (สมมติเป็นเท็จแล้วไล่หาข้อขัดแย้ง เหมือนแท็บที่แล้ว)
3
เป็นสัจนิรันดร์ = สมเหตุสมผล
4
ไม่เป็นสัจนิรันดร์ = ไม่สมเหตุสมผล (มีกรณีที่เหตุจริงหมดแต่ผลเท็จ)

An argument is valid when "if every premise is true, the conclusion must be true too". The trick is to turn it into a tautology question and reuse the same method.

1
Join all premises with ∧, then point them at the conclusion with →  →  (P₁ ∧ P₂ ∧ ...) → C
2
Test whether it is a tautology (assume false, look for a contradiction — same as the previous tab).
3
Tautology = valid argument
4
Not a tautology = invalid (there is a case where every premise is true but the conclusion is false).
✅ตรวจสอบการอ้างเหตุผลของคุณเอง
ตัวอย่าง: Modus Ponens: p → q, p ∴ q Modus Tollens: p → q, ~q ∴ ~p ผิดพลาดยอดฮิต: p → q, q ∴ p
∀ประโยคเปิดและตัวบ่งปริมาณ

ประโยคเปิด P(x) คือประโยคที่มีตัวแปร ยังบอกจริง/เท็จไม่ได้จนกว่าจะรู้ว่า x คืออะไร — วิธีทำให้กลายเป็นประพจน์มี 2 ทาง คือ แทนค่า หรือ ใส่ตัวบ่งปริมาณ

สัญลักษณ์อ่านว่าจริงเมื่อ
∀xสำหรับ x ทุกตัวต้องจริง ทุกตัว (เจอตัวเดียวที่เท็จ ก็เท็จทั้งประโยค)
∃xมี x บางตัวขอแค่ ตัวเดียว ที่จริง ก็จริงทั้งประโยค
ตัวอย่าง เอกภพสัมพัทธ์คือจำนวนจริง
∀x[x² ≥ 0] — จริง เพราะกำลังสองของจำนวนจริงไม่มีทางติดลบ
∃x[x + 2 = 3] — จริง เพราะมี x = 1 ที่ใช้ได้
∀x[x + 2 = 3] — เท็จ เพราะ x = 5 ก็ทำให้ผิดแล้ว

An open sentence P(x) contains a variable and has no truth value until you know what x is. Two ways to turn it into a proposition: substitute a value, or add a quantifier.

SymbolRead asTrue when
∀xfor all xtrue for every value (one counterexample makes it false)
∃xthere exists an xone value that works is enough
Examples (universe: the real numbers)
∀x[x² ≥ 0] — true: no real square is negative.
∃x[x + 2 = 3] — true: x = 1 works.
∀x[x + 2 = 3] — false: x = 5 already breaks it.
🔄นิเสธของตัวบ่งปริมาณ (สมบัติข้อ 22–23)
~∀x[P(x)] ≡ ∃x[~P(x)]
~∃x[P(x)] ≡ ∀x[~P(x)]
จำง่ายๆ: ใส่นิเสธเข้าไปข้างใน แล้ว สลับตัวบ่งปริมาณ — ∀ กลายเป็น ∃, ∃ กลายเป็น ∀ และตัวประโยคข้างในติดนิเสธไปด้วย
Easy memory: push the negation inside and flip the quantifier — ∀ becomes ∃, ∃ becomes ∀, and the inner sentence gets negated.

ตัวอย่างการคำนวณ

ตัวอย่าง 1   จงหานิเสธของ ∀x[x > 0]
① ติดนิเสธหน้าประโยค: ~∀x[x > 0]
② ใช้สมบัติข้อ 22 สลับ ∀ → ∃ แล้วนิเสธข้างใน: ∃x[~(x > 0)]
③ จัดรูปข้างใน: ∃x[x ≤ 0]
อ่านเป็นภาษาคน: "ไม่ใช่ว่าทุกตัวมากกว่าศูนย์" = "มีบางตัวที่ไม่มากกว่าศูนย์"
ตัวอย่าง 2   จงหานิเสธของ ∃x[x² = 2]
① ติดนิเสธ: ~∃x[x² = 2]
② ใช้สมบัติข้อ 23 สลับ ∃ → ∀: ∀x[~(x² = 2)]
③ จัดรูป: ∀x[x² ≠ 2]
ตัวอย่าง 3 (มีตัวเชื่อมข้างใน)   จงหานิเสธของ ∀x[P(x) ∧ Q(x)]
① สมบัติข้อ 22: ∃x[~(P(x) ∧ Q(x))]
② De Morgan (สมบัติข้อ 5): ∃x[~P(x) ∨ ~Q(x)]
ข้างในวงเล็บใช้สมบัติ 23 ข้อได้ตามปกติเลย
Example 1   Negate ∀x[x > 0]
① Attach the negation: ~∀x[x > 0]
② Law 22 flips ∀ → ∃ and negates the inside: ∃x[~(x > 0)]
③ Tidy up: ∃x[x ≤ 0]
In words: "not every value is positive" = "some value is not positive".
Example 2   Negate ∃x[x² = 2]
① Attach the negation: ~∃x[x² = 2]
② Law 23 flips ∃ → ∀: ∀x[~(x² = 2)]
③ Tidy up: ∀x[x² ≠ 2]
Example 3 (connective inside)   Negate ∀x[P(x) ∧ Q(x)]
① Law 22: ∃x[~(P(x) ∧ Q(x))]
② De Morgan (law 5): ∃x[~P(x) ∨ ~Q(x)]
Inside the bracket you may use all 23 laws as usual.
⚠️ เครื่องมือเชิงโต้ตอบในแท็บอื่นรับเฉพาะ ประพจน์ (ตัวแปร p, q, r ที่แจกแจง T/F ได้) — ประโยคที่มี ∀ หรือ ∃ พิมพ์เข้าไปไม่ได้ เพราะเอกภพสัมพัทธ์อาจมีสมาชิกไม่จำกัด แจกแจงเป็นตารางไม่ได้
⚠️ The interactive tools in the other tabs only accept propositions (variables p, q, r that can be enumerated as T/F). Sentences with ∀ or ∃ cannot be typed in, because the universe may be infinite and cannot be listed in a table.
