# ค่าสไตล์ "ฟอนต์ไวรัล" และเหตุผลเบื้องหลัง

อ่านไฟล์นี้เมื่อจะแก้ค่าสไตล์ ย้ายตำแหน่งข้อความ หรือสงสัยว่าทำไมตัวเลขถึงเป็นแบบนี้
ถ้าแค่ตัดคลิปตามสูตรเดิม ไม่ต้องอ่าน — `build_clip.py` ใส่ค่าพวกนี้ให้อยู่แล้ว

## ที่มาของค่าสี/ฟอนต์

สูตรที่ครีเอเตอร์สายตัดต่อไทยแชร์กันใน CapCut คือ:

| ช่องใน CapCut | ค่า |
|---|---|
| ขนาด | 9–10 |
| สี | ขาว + เหลือง |
| สโตรค | 10 |
| อายแชโดว์ | 80 |
| ฟอนต์พาดหัว | คณิต-SB / คณิต-Bd |

**"คณิต" คือชื่อไทยของฟอนต์ Kanit ใน CapCut** — เป็นฟอนต์ฟรีของ Cadson Demak อยู่ใน
Google Fonts โหลดผ่าน `setup.sh` ได้เลย ฉะนั้นงานที่เรนเดอร์ด้วย ffmpeg จะได้ฟอนต์ตรงกับ
ที่คลิปไวรัลใช้จริง ไม่ใช่ของเทียบเคียง

**สีเหลือง `RGB(255, 217, 37)`** ไม่ได้เดา — ดูดมาจากพิกเซลในคลิปอ้างอิงจริง (คลิป
ckfastwork) โดยครอปโซนตัวอักษร ดัมพ์เป็น rgb24 แล้วหาค่าที่พบบ่อยที่สุด ถ้าจะเปลี่ยนสี
ควรดูดจากคลิปที่อยากเลียนแบบด้วยวิธีเดียวกัน อย่ากะเอาเอง

ในไฟล์ `.ass` สีเขียนกลับด้านเป็น BGR: `&H00` + `BB` + `GG` + `RR`
ดังนั้น `RGB(255,217,37)` -> `&H0025D9FF&`

## แปลงค่า CapCut มาเป็น ffmpeg/ASS

| CapCut | ในสคริปต์นี้ (ฐาน 1080×1920) |
|---|---|
| ขนาด 9–10 (บรรทัดเน้น) | `Fontsize 96` |
| ขนาดบรรทัดรอง | `Fontsize 60` |
| สโตรค 10 | `Outline 7` |
| อายแชโดว์ 80 | `Shadow 5` + `BackColour &HC8000000` |

ค่าพวกนี้ผูกกับ `PlayResX/Y` ที่ประกาศไว้ ถ้าเปลี่ยนความละเอียดปลายทาง ให้เปลี่ยน
`PlayResX/Y` ตาม แล้ว libass จะสเกลสโตรคกับเงาให้เอง (เพราะตั้ง `ScaledBorderAndShadow: yes`)

## ตำแหน่งข้อความ กับโซนที่ UI แพลตฟอร์มบัง

TikTok/Reels/Shorts เอา UI ของตัวเองทับคลิปเสมอ:

- **ล่างสุดราว 17%** — ชื่อบัญชี แคปชั่น แถบเล่น
- **ขวาสุดราว 17%** — ปุ่มไลก์/คอมเมนต์/แชร์
- **บนสุดราว 4%** — ปุ่มย้อนกลับ ค้นหา

`build_clip.py` จึงวางป้ายคีย์เวิร์ดแบบยึดก้นตัวอักษรไว้ที่ **82.8% ของความสูง**
(`\an2` + `\pos`) คือสูงพอให้พ้น UI ล่าง แต่ยังต่ำพอให้ไม่บังเนื้อหากลางจอ
ถ้าคลิปต้นฉบับมีแถบว่างอยู่แล้ว อย่าเพิ่งดีใจแล้วเอาข้อความไปหย่อนไว้ในแถบล่างสุด —
แถบนั้นมักอยู่ในโซนที่ UI บังพอดี

พาดหัว (hook) ใช้ `\an8` ชิดบน ถ้าคลิปต้นฉบับมีแถบสีทึบด้านบน ให้วางในแถบนั้น
จะดูเหมือนออกแบบมาคู่กันตั้งแต่แรก

## ทำไมป้ายถึงเป็นสองบรรทัด

คลิปอ้างอิงวาง **เหลืองตัวใหญ่ = คำที่อยากให้จำ** และ **ขาวตัวเล็ก = บริบท**
สายตาจับคำเหลืองก่อนแล้วค่อยไล่ลงมาอ่านคำอธิบาย

บางป้ายอ่านแล้วต่อกันเป็นประโยคเดียว เช่น "ไล่ให้เจอคู่ที่ / คูณกันได้ −12 บวกกันได้ 1"
กรณีนี้ให้สลับเป็น `"layout": "WY"` — ขาวเล็กขึ้นก่อน เหลืองใหญ่ตามหลัง ประโยคจะอ่าน
เรียงลงมาถูกลำดับ และตัวเลขยังได้ตัวใหญ่สีเหลืองอยู่ดี

## ข้อจำกัดความกว้าง

ที่ `Fontsize 96` บนจอกว้าง 1080 ตัวอักษรไทยพอดีประมาณ **20–22 ตัว** ต่อบรรทัด
ยาวกว่านั้นจะล้นขอบเงียบๆ — `libass` ไม่เตือน ต้องดึงเฟรมออกมาดูเอง
ถ้าล้น ให้ตัดคำให้สั้นลงก่อน ค่อยคิดเรื่องลดขนาดฟอนต์ (ลดขนาดแล้วจะหลุดสไตล์ไวรัลทันที)

## แอนิเมชันเด้ง

```
\fad(90,90)\fscx55\fscy55\t(0,130,\fscx106\fscy106)\t(130,230,\fscx100\fscy100)
```

ย่อจาก 55% แล้วเด้งเกินไป 106% ก่อนกลับมา 100% ภายใน 230 มิลลิวินาที
เลียนจังหวะ pop ของ CapCut ถ้าอยากได้นุ่มกว่านี้ให้ลดตัวเกิน 106 เหลือ 102
