▦ผลรวมรีมันน์: พื้นที่จากแท่งสี่เหลี่ยมย่อย

แบ่ง [a,b] เป็น n ช่องเท่าๆ กัน สร้างแท่งสี่เหลี่ยมสูง f(xᵢ) แล้วรวมพื้นที่ทั้งหมด — เมื่อ n → ∞ ผลรวมนี้เข้าใกล้พื้นที่จริงใต้กราฟ นิยามว่าเป็นปริพันธ์จำกัดเขต

∫ab f(x) dx  =  limn→∞ Σ f(xᵢ)·Δx
🎚️เพิ่ม n ดูแท่งสี่เหลี่ยมแคบลงจนเข้าใกล้พื้นที่จริง — f(x) = x²+1 บน [0,1]

🧮ตัวอย่างการคำนวณ — ภาค 1 (ดิฟตัดอินทิเกรต)

ตัวอย่าง (ก)   หา F′(x) เมื่อ F(x) = ∫1x (t² + 1) dt

① ภาค 1 บอกว่า ddx ∫ax f(t) dt = f(x) — อนุพันธ์ “ตัด” ปริพันธ์ทิ้ง
② ในที่นี้ f(t) = t² + 1 และขอบล่าง a = 1 — ขอบล่างเป็นค่าคงที่ จึงไม่มีผลต่อคำตอบ
③ แทน t ด้วย x ในตัวฟังก์ชันได้เลย ไม่ต้องหาปฏิยานุพันธ์ก่อน
④ ผลลัพธ์: F′(x) = x² + 1   (ลองเช็ก: F(x) = x³3 + x − 43 ดิฟแล้วได้ x² + 1 จริง)

ตัวอย่าง (ข)   ขอบบนเป็นฟังก์ชัน — หา F′(x) เมื่อ F(x) = ∫0x² sin t dt

① ขอบบนไม่ใช่ x เฉยๆ แต่เป็น g(x) = x² — ใช้ภาค 1 ตรงๆ ไม่ได้ ต้องพ่วงกฎลูกโซ่
② ตั้ง H(u) = ∫0u sin t dt จะได้ F(x) = H(g(x))
③ จากภาค 1: H′(u) = sin u  และ  g′(x) = 2x
④ กฎลูกโซ่: F′(x) = H′(g(x))·g′(x) = sin(x²)·2x
⑤ ผลลัพธ์: F′(x) = 2x·sin(x²)
🧮ตัวอย่างการคำนวณ — ภาค 2 (สูตรคำนวณ F(b) − F(a))

ตัวอย่าง (ก)   หา ∫13 (x² + 1) dx

① หาปฏิยานุพันธ์ F ของ f(x) = x² + 1 ก่อน: F(x) = x³3 + x   (ไม่ต้องใส่ +C เพราะเดี๋ยวก็ตัดกันตอนลบ)
② ภาค 2: ∫ab f(x) dx = F(b) − F(a) — เขียนย่อเป็น [F(x)]ab
③ F(3) = 273 + 3 = 12  ,  F(1) = 13 + 1 = 43
④ ผลลัพธ์: ∫13 (x² + 1) dx = 12 − 43 = 323

ตัวอย่าง (ข)   หา ∫0π2 cos x dx

① ปฏิยานุพันธ์ของ cos x คือ sin x
② ∫0π2 cos x dx = [sin x]0π2
③ = sin(π2) − sin(0) = 1 − 0
④ ผลลัพธ์: ∫0π2 cos x dx = 1

📜พิสูจน์ทฤษฎีบทหลักมูลของแคลคูลัส ทั้งสองภาค

อ่านคู่กันซ้าย–ขวา: ภาค 1 อธิบายว่าทำไม “ดิฟถึงตัดอินทิเกรตได้” ส่วนภาค 2 ต่อยอดจากตรงนั้นไปเป็นสูตรคำนวณ F(b) − F(a)

ภาค 1 — ดิฟตัดอินทิเกรต
ข้ออ้าง: ถ้า f ต่อเนื่องบน [a,b] และ F(x) = ∫ax f(t) dt แล้ว F′(x) = f(x) ทุก x ใน (a,b)
① เริ่มจากนิยามอนุพันธ์ของ F:   F′(x) = limh→0 F(x+h) − F(x)h
② สมบัติการบวกช่วงของปริพันธ์:   F(x+h) − F(x) = ∫xx+h f(t) dt   (พื้นที่ถึง x+h ลบพื้นที่ถึง x เหลือเฉพาะแถบ [x, x+h])
③ ให้ h > 0 และให้ m, M เป็นค่าต่ำสุดและค่าสูงสุดของ f บนช่วงปิด [x, x+h]   (มีจริงเสมอ เพราะ f ต่อเนื่องบนช่วงปิด — ทฤษฎีบทค่าสุดขีด)
④ ตีกรอบแถบนั้นด้วยสี่เหลี่ยมสองอัน สูง m กับสูง M กว้าง h เท่ากัน:   m·h ≤ ∫xx+h f(t) dt ≤ M·h
h h = 1.70

ลาก h เพื่อย่อแถบ [x, x+h] ให้แคบลง — สี่เหลี่ยมเขียว (สูง m) และสี่เหลี่ยมส้ม (สูง M) หนีบพื้นที่ของแถบไว้เสมอ และเมื่อ h → 0 ทั้ง m และ M ต่างวิ่งเข้าหา f(x) ค่าเดียวกัน ผลหารเชิงผลต่างตรงกลางจึงไม่มีที่ไป นอกจากลู่เข้า f(x) ด้วย

⑤ หารทุกข้างด้วย h  (h > 0 เครื่องหมายไม่กลับ):   m ≤ F(x+h) − F(x)h ≤ M
⑥ เมื่อ h → 0 ช่วง [x, x+h] หดลงเหลือจุด x เดียว และเพราะ f ต่อเนื่อง จึงได้ m → f(x) และ M → f(x)
⑦ ตัวกลางถูกขนาบด้วยสองข้างที่ลู่เข้าค่าเดียวกัน — ทฤษฎีบทแซนด์วิช บังคับให้ตัวกลางลู่เข้า f(x) ด้วย
⑧ กรณี h < 0 ทำอย่างเดียวกันบนช่วง [x+h, x] ได้ผลเท่ากัน จึงเป็นลิมิตสองข้างจริง
⑨ ด้านซ้ายของ ⑤ คือนิยามของ F′(x) พอดี  ⇒  F′(x) = f(x)  นั่นคือ ddx ∫ax f(t) dt = f(x)
∎
พิสูจน์นี้ไม่ใช้เครื่องหมาย ≈ เลย — แทนที่การประมาณด้วยการตีกรอบ m·h ≤ … ≤ M·h แล้วบีบด้วยแซนด์วิช
ภาค 2 — สูตรคำนวณ F(b) − F(a)
ข้ออ้าง: ถ้า f ต่อเนื่องบน [a,b] และ f(x) ≥ 0 ทุก x ∈ [a,b] และ F เป็นปฏิยานุพันธ์ใดๆ ของ f แล้ว ∫ab f(x) dx = F(b) − F(a)
① ให้ y = f(x) ต่อเนื่องบนช่วง [a,b] และ f(x) ≥ 0 สำหรับทุก x ∈ [a,b]
② ให้ R เป็นพื้นที่ปิดล้อมด้วยเส้นโค้ง y = f(x) กับแกน x จากเส้นตรง x = a ถึง x = b

R คือพื้นที่ทั้งผืนที่ปิดล้อมด้วยเส้นโค้ง y = f(x) แกน x และเส้นตรง x = a กับ x = b

③ ให้ A(x) แทนพื้นที่ปิดล้อมด้วย y = f(x) กับแกน x จาก a ถึง x เมื่อ a ≤ x ≤ b  ⇒  ∫ax f(x) dx = A(x)

A(x) คือพื้นที่เท่าที่สะสมมาถึง x — ขยับ x ไปทางขวา พื้นที่ก็โตขึ้น ที่ x = a ยังไม่มีพื้นที่เลย (A(a) = 0) และที่ x = b ได้พื้นที่เต็มผืน (A(b) = R)

④ ที่ขอบซ้าย:   A(a) = ∫aa f(x) dx = 0   (ช่วงกว้างศูนย์ ไม่เหลือพื้นที่)
⑤ ที่ขอบขวา:   A(b) = ∫ab f(x) dx = R
⑥ พิจารณาแถบบางกว้าง h ที่ x:   A(x+h) − A(x) ≈ f(x)·h   (แถบเกือบเป็นสี่เหลี่ยมสูง f(x) กว้าง h)
h h = 0.75

แถบสีส้มคือ A(x+h) − A(x) ซึ่งเกือบเป็นสี่เหลี่ยมสูง f(x) กว้าง h (กรอบเส้นประ) — ยิ่ง h เล็ก ส่วนที่เกินออกมาจากกรอบยิ่งน้อยลง จึงเขียนได้ว่า A(x+h) − A(x) ≈ f(x)·h

⑦ ย้ายข้าง:   f(x) = A(x+h) − A(x)h
⑧ ให้ h → 0:   f(x) = limh→0 A(x+h) − A(x)h = A′(x)
⑨ จะได้ A(x) เป็นปฏิยานุพันธ์ของ f(x)  นั่นคือ  F(x) = A(x) + C
⑩ แทน x = a:   F(a) = A(a) + C = 0 + C  ⇒  F(a) = C   (ใช้ ④)
⑪ แทน x = b:   F(b) = A(b) + C = A(b) + F(a)
⑫ ย้ายข้าง:   F(b) − F(a) = A(b) = R   (ใช้ ⑤)
⑬ ดังนั้น   R = ∫ab f(x) dx = F(b) − F(a)
∎
เรียบเรียงตามเอกสาร “พิสูจน์ทฤษฎีบทหลักมูล แคลคูลัส บทที่ 2” แนวพื้นที่ปิดล้อม
สองพิสูจน์นี้ซ้อนกันตรงไหน: ขั้น ⑥–⑧ ของภาค 2 (A(x+h) − A(x) ≈ f(x)·h จนได้ A′(x) = f(x)) คือใจความเดียวกับภาค 1 เป๊ะๆ ต่างกันที่ภาค 2 ใช้เครื่องหมาย ≈ ซึ่งยังไม่ได้พิสูจน์ว่าส่วนที่เหลือหายไปจริงเมื่อ h → 0 — คอลัมน์ซ้ายจึงเป็นการทำสามขั้นนั้นให้รัดกุม โดยแทน ≈ ด้วยการตีกรอบ m·h ≤ … ≤ M·h แล้วบีบด้วยทฤษฎีบทแซนด์วิช ส่วนที่เป็นของภาค 2 จริงๆ คือขั้น ⑨–⑬ ที่ต่อยอดด้วย F = A + C จนค่าคงที่ C ตัดกันหายไป
ข้อควรระวังกับเงื่อนไข f(x) ≥ 0: คอลัมน์ขวาตั้งเงื่อนไขนี้ไว้เพื่อให้พูดถึง “พื้นที่” ได้ตรงๆ แต่ตัวทฤษฎีบทภาค 2 ใช้ได้แม้ f ติดลบ — เพียงเปลี่ยนจากการอ้างพื้นที่ ไปนิยาม A(x) = ∫ax f(t) dt แล้วอ้างภาค 1 ว่า A′(x) = f(x) แทน ขั้น ⑨–⑬ ที่เหลือใช้ได้เหมือนเดิมทุกบรรทัด
