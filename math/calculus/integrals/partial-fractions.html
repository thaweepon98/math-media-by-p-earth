➗ เศษส่วนย่อย

แยกเศษส่วนย่อย 3 กรณี สำหรับปริพันธ์ของฟังก์ชันตรรกยะ

➗แนวคิด: แยก P(x)/Q(x) เป็นเศษส่วนย่อยๆ

ใช้เมื่อ f คือฟังก์ชันตรรกยะ P(x)/Q(x) (ดีกรี P น้อยกว่า Q) — แยกตัวส่วนเป็นตัวประกอบก่อน แล้วแยกเศษส่วนตามชนิดของตัวประกอบ 3 กรณี

กรณี 1: ตัวประกอบเชิงเส้นไม่ซ้ำ
P(x)(x−a)(x−b) = Ax−a + Bx−b
กรณี 2: ตัวประกอบเชิงเส้นซ้ำ
P(x)(x−a)² = Ax−a + B(x−a)²
กรณี 3: ตัวประกอบกำลังสองลดทอนไม่ได้
P(x)x(x²+1) = Ax + Bx+Cx²+1
🧮ตัวอย่าง: หาค่า A, B ของ (x−2)/[(x+1)(x−3)]

วิธีเร็ว (cover-up method): แทนค่า x ที่ทำให้แต่ละตัวประกอบเป็น 0 ลงในสมการหลังคูณตลอดด้วยตัวส่วนร่วมแล้ว

สรุป: หลังแยกเศษส่วนย่อยแล้ว แต่ละเทอมกลายเป็นปริพันธ์รูป ∫A/(x−a)dx = A·ln|x−a| + C ซึ่งหาได้ง่ายกว่าฟังก์ชันตรรกยะตั้งต้นมาก
