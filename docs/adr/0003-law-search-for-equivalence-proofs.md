# 3. ค้นหาลำดับสมบัติ 23 ข้อเองด้วยการค้นหา (search) แทนพึ่งไลบรารีสำเร็จรูปหรือโชว์แค่ตารางค่าความจริง

วันที่: 2026-09-06

## สถานะ

ตกลงแล้ว

## บริบท

สื่อ `math/logic.html` (ตรรกศาสตร์) มีแท็บ **สมมูล**, **สัจนิรันดร์**, **สมเหตุสมผล** ที่ให้นักเรียนพิมพ์ประพจน์เอง
แล้วต้องการเห็น "วิธีทำ" ตามทริกที่ครูจดสรุปไว้ (ดู `CONTEXT.md` หัวข้อ "ตรรกศาสตร์: คำที่ต้องแยกให้ชัด") —
สำหรับสมมูลคือการไล่ใช้สมบัติ 23 ข้อแปลงข้างหนึ่งไปให้ตรงกับอีกข้าง ไม่ใช่แค่บอกว่า "สมมูล/ไม่สมมูล"

ทางเลือกที่ชัดเจนที่สุดคือแค่เช็คด้วยตารางค่าความจริง (2 นิพจน์ให้ค่าตรงกันทุกแถวหรือไม่) — เร็ว แม่นยำ
100% เขียนง่าย แต่ **ไม่ตอบโจทย์ทริกที่ครูอยากสอน** เพราะนักเรียนจะไม่เห็นว่าทำไมถึงสมมูล ใช้สมบัติข้อไหนบ้าง

อีกทางคือพึ่ง CAS/ตัวพิสูจน์สำเร็จรูป (nerdamer, Algebrite ฯลฯ) จาก CDN — แต่ขัดกับข้อกำหนดหลักของ
โปรเจกต์ที่ทุกไฟล์ต้องเปิดผ่าน `file://` แบบออฟไลน์ 100% (เหตุผลเดียวกับ ADR 0001) และ CAS ทั่วไปก็ไม่ได้
ออกแบบมาให้แสดงเป็น "ขั้นตอนอ้างอิงสมบัติข้อที่เท่าไร" แบบที่ตำราไทยใช้อยู่ดี ต้องเขียน mapping เพิ่มอยู่ดี

## การตัดสินใจ

เขียน tokenizer + parser + ตัวประเมินค่าความจริงเองใน `<script>` ของไฟล์ (ครอบคลุม ∧ ∨ → ↔ ~ และตัวแปร
p,q,r สูงสุด 3 ตัว) แบ่งเป็น 2 ชั้นทำงานคนละหน้าที่ตามที่นิยามใน `CONTEXT.md`:

1. **ตัวตัดสิน (arbiter)** — สร้างตารางค่าความจริงเปรียบเทียบ 2 นิพจน์ ตัดสินสมมูล/ไม่สมมูลเสมอ ห้ามผิด
2. **วิธีทำที่แสดง (displayed method)** — ค้นหาลำดับการใช้สมบัติ 23 ข้อ (bounded search, เช่น
   iterative-deepening ทั้งสองทาง ซ้าย→ขวา และ ขวา→ซ้าย พบกันตรงกลาง) เพื่อประกอบเป็นขั้นตอนแสดงผล
   โดยอ้างอิงหมายเลขสมบัติเดียวกับตารางในแท็บที่ 2

ถ้าค้นหาไม่เจอภายในจำนวนขั้นที่กำหนด (เคสยาก/นิพจน์ซับซ้อน) ต้องแจ้งตรงๆ ว่า "ยืนยันด้วยตารางค่าความจริง
ว่า[สมมูล/ไม่สมมูล] แต่ไม่พบวิธีลัดด้วยสมบัติ" — ห้ามเงียบหรือมั่วขั้นตอนเด็ดขาด (หลักการเดียวกับ ADR 0001)

เอนจินสมมติ-เป็น-เท็จ (tableau) ของแท็บสัจนิรันดร์/สมเหตุสมผลใช้หลักการเดียวกัน: ตัวตัดสินคือตรวจว่ามีแถว
ใดในตารางค่าความจริงที่ทำให้ทั้งนิพจน์เป็นเท็จหรือไม่ ส่วนต้นไม้กิ่ง T/F ที่วาดให้ดูเป็นแค่ "วิธีทำที่แสดง"

## ผลที่ตามมา

- ไฟล์ยังเปิดออฟไลน์ได้ 100% เหมือนสื่ออื่นทุกชิ้น ไม่มี dependency ภายนอก
- ขอบเขตที่รองรับ (≤3 ตัวแปร, ตัวเชื่อม 5 ตัว) ตรงกับสิ่งที่แท็บสมบัติ 23 ข้อสอนพอดี
- **แลกมาด้วย**: การค้นหาอาจไม่เจอ "วิธีที่สวยที่สุดตามตำรา" เสมอไป และสำหรับนิพจน์ซับซ้อนมากอาจหา
  ไม่เจอเลย (ต้อง fallback ไปบอกผลจากตารางค่าความจริงแทน) — ถ้าครูเจอเคสที่ระบบหาไม่เจอบ่อยเกินไป
  ควรทบทวน ADR นี้ใหม่ (เช่น เพิ่ม heuristic การเลือกสมบัติ หรือจำกัดความยาวนิพจน์ที่รับ)
- ต้องมีเคสทดสอบว่า arbiter กับวิธีทำที่แสดงไม่มีวันขัดแย้งกัน (วิธีทำหาไม่เจอได้ แต่คำตอบสุดท้ายต้องตรงกับ
  ตัวตัดสินเสมอ)
