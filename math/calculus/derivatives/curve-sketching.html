📈 ความเว้าและการร่างกราฟ

ความเว้า • จุดเปลี่ยนเว้า • เส้นกำกับ • ตัวอย่างร่างกราฟเต็มรูปแบบ

🌗ความเว้าและจุดเปลี่ยนเว้า

f″(x) > 0 บนช่วง (a,b) ⇒ กราฟเว้าขึ้น (concave up)  •  f″(x) < 0 ⇒ กราฟเว้าลง (concave down) — จุดที่ความเว้าเปลี่ยนเรียกว่า จุดเปลี่ยนเว้า (inflection point) ซึ่งมักเกิดที่ f″(x) = 0

กราฟของฟังก์ชัน f(x) = x³/3 − x (ลากจุดสีน้ำเงินเข้ม)
ข้อควรระวัง: x=−1 และ x=1 ที่ทำเครื่องหมายไว้เป็นจุดสูงสุด/ต่ำสุดเฉพาะที่ (f′=0) ของกราฟตัวอย่างนี้เท่านั้น ไม่ใช่จุดเปลี่ยนเว้า — จุดเปลี่ยนเว้าที่แท้จริง (จุดที่ f″ เปลี่ยนเครื่องหมาย) อยู่ที่ x=0 (จุดสีชมพู) เท่านั้น
📍เส้นกำกับ (Asymptotes)

เส้นกำกับแนวดิ่ง x = a เกิดเมื่อ lim ที่ x→a⁺ หรือ x→a⁻ ของ f(x) เป็น ±∞ • เส้นกำกับแนวราบ y = L เกิดเมื่อ lim ที่ x→±∞ ของ f(x) = L

กราฟของฟังก์ชัน f(x) = 1/(x−1)
🗺️ตัวอย่าง: จงวิเคราะห์และร่างกราฟ f(x) = (x²+x)/(x−2)
