      ⭕แผนภาพเวนน์
      🔀เลือกจำนวนเซต
      🔢กรอกจำนวนสมาชิก แล้วดูตัวเลขในแผนภาพทันที
      👁️เลือกว่าจะโชว์ตัวเลขส่วนไหนในแผนภาพ

      n(A∪B) = 0

      👁️เลือกว่าจะโชว์ตัวเลขส่วนไหนในแผนภาพ
      ⭕แผนภาพเวนน์
      n(A∪B∪C) = 0
      ❓ปัญหา: การนับซ้ำ

      ถ้าเราอยากรู้ว่า A กับ B รวมกันมีสมาชิกกี่ตัว แล้วลองเอา n(A) + n(B) ตรงๆ สมาชิกที่อยู่ใน ทั้ง A และ B (คือ A∩B) จะถูกนับไป 2 ครั้ง — ครั้งหนึ่งตอนนับ A อีกครั้งตอนนับ B จึงต้อง ลบส่วนที่นับซ้ำออก 1 ครั้ง

      If we want to know how many elements A and B have together, and simply add n(A) + n(B) directly — elements that are in both A and B (that is, A∩B) get counted twice — once when counting A, again when counting B — so we must subtract the double-counted part once

      n(A∪B) = n(A) + n(B) − n(A∩B)
      🧩เมื่อมี 3 เซต ยิ่งซับซ้อนขึ้น
      1
      บวก n(A) + n(B) + n(C) ก่อน — แต่สมาชิกที่อยู่ในคู่ที่ซ้อนกัน (A∩B, A∩C, B∩C) จะถูกนับ 2 ครั้ง
      First add n(A) + n(B) + n(C) — but elements in an overlapping pair (A∩B, A∩C, B∩C) get counted twice
      2
      ลบ n(A∩B) + n(A∩C) + n(B∩C) ออก เพื่อแก้การนับซ้ำของคู่ — แต่สมาชิกที่อยู่ใน ทั้งสามเซตพร้อมกัน (A∩B∩C) ถูกบวกไป 3 ครั้ง (ตอนนับ A, B, C) แล้วถูกลบไป 3 ครั้ง (ตอนลบ A∩B, A∩C, B∩C) จึงกลายเป็น 0 ครั้ง — หายไปเลย!
      Subtract n(A∩B) + n(A∩C) + n(B∩C) to fix the pairwise double-counting — but elements in all three sets at once (A∩B∩C) were added 3 times (while counting A, B, C) then subtracted 3 times (while subtracting A∩B, A∩C, B∩C), leaving 0 times — they vanish!
      3
      จึงต้อง บวก n(A∩B∩C) กลับเข้ามา 1 ครั้ง เพื่อให้สมาชิกกลุ่มนี้ถูกนับพอดี 1 ครั้ง
      So we must add n(A∩B∩C) back once so this group of elements ends up counted exactly once
      n(A∪B∪C) = n(A)+n(B)+n(C) − n(A∩B) − n(A∩C) − n(B∩C) + n(A∩B∩C)
      💡 ย้อนทวนสิ่งที่เพิ่งลอง: ตอนอยู่แท็บ "แผนภาพเวนน์เชิงโต้ตอบ" ที่กดปุ่มแต่ละพจน์ของสูตรเมื่อครู่นี้ สังเกตตัวเลขกำกับกลางแต่ละชิ้นส่วนของวงกลม — มันขึ้นๆ ลงๆ ตามพจน์ที่กด และจะนิ่งที่ 1 ทุกชิ้นส่วน ก็ต่อเมื่อกดครบสูตรที่ถูกต้องเท่านั้น — นั่นแหละคือที่มาของสูตรด้านบน
