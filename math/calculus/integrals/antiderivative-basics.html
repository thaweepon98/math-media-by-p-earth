∫ ปฏิยานุพันธ์และกฎพื้นฐาน

นิยามปฏิยานุพันธ์ • ค่าคงตัว +C • ตารางสูตรปริพันธ์

🔄ปฏิยานุพันธ์: การหาอนุพันธ์แบบย้อนกลับ

ถ้า F′(x) = f(x) เรียก F ว่า ปฏิยานุพันธ์ (antiderivative) ของ f — แต่ปฏิยานุพันธ์ไม่ได้มีหนึ่งเดียว: ถ้า F เป็นปฏิยานุพันธ์หนึ่งของ f แล้ว F(x) + C ก็เป็นปฏิยานุพันธ์ของ f ด้วยเสมอ ไม่ว่า C จะเป็นค่าคงที่ใด (เพราะอนุพันธ์ของค่าคงที่คือ 0)

∫ f(x) dx = F(x) + C
🎚️ลาก C ดูตระกูลของปฏิยานุพันธ์ของ f(x) = x²

ทุกเส้นในตระกูลนี้มีความชันเท่ากันที่ x เดียวกันเสมอ (เพราะอนุพันธ์เท่ากับ f(x) = x² เหมือนกันหมด) ต่างกันแค่เลื่อนขึ้นลงตามค่า C
