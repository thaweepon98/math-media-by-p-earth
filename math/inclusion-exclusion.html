🔀 จำนวนสมาชิกของเซตจำกัด

Inclusion-Exclusion Principle • สื่อการสอนแบบโต้ตอบ

❓ปัญหา: การนับซ้ำ

ถ้าเราอยากรู้ว่า A กับ B รวมกันมีสมาชิกกี่ตัว แล้วลองเอา n(A) + n(B) ตรงๆ สมาชิกที่อยู่ใน ทั้ง A และ B (คือ A∩B) จะถูกนับไป 2 ครั้ง — ครั้งหนึ่งตอนนับ A อีกครั้งตอนนับ B จึงต้อง ลบส่วนที่นับซ้ำออก 1 ครั้ง

n(A∪B) = n(A) + n(B) − n(A∩B)
🧩เมื่อมี 3 เซต ยิ่งซับซ้อนขึ้น
1
บวก n(A) + n(B) + n(C) ก่อน — แต่สมาชิกที่อยู่ในคู่ที่ซ้อนกัน (A∩B, A∩C, B∩C) จะถูกนับ 2 ครั้ง
2
ลบ n(A∩B) + n(A∩C) + n(B∩C) ออก เพื่อแก้การนับซ้ำของคู่ — แต่สมาชิกที่อยู่ใน ทั้งสามเซตพร้อมกัน (A∩B∩C) ถูกบวกไป 3 ครั้ง (ตอนนับ A, B, C) แล้วถูกลบไป 3 ครั้ง (ตอนลบ A∩B, A∩C, B∩C) จึงกลายเป็น 0 ครั้ง — หายไปเลย!
3
จึงต้อง บวก n(A∩B∩C) กลับเข้ามา 1 ครั้ง เพื่อให้สมาชิกกลุ่มนี้ถูกนับพอดี 1 ครั้ง
n(A∪B∪C) = n(A)+n(B)+n(C) − n(A∩B) − n(A∩C) − n(B∩C) + n(A∩B∩C)
💡 ลองด้วยตัวเอง: ไปที่แท็บ "แผนภาพเวนน์เชิงโต้ตอบ" แล้วลองกดปุ่มแต่ละพจน์ของสูตรตามลำดับใดก็ได้ สังเกตตัวเลขกำกับกลางแต่ละชิ้นส่วนของวงกลม — มันจะขึ้นๆ ลงๆ ตามพจน์ที่กด และจะนิ่งที่ 1 ทุกชิ้นส่วน ก็ต่อเมื่อกดครบสูตรที่ถูกต้องเท่านั้น
🔀เลือกโหมด
🔢จำนวนสมาชิกที่กำหนดให้
🎛️กดปุ่มตามพจน์ของสูตร (กดลำดับใดก็ได้)
n(A∪B) = |A| + |B| − |A∩B|
ผลรวมจากพจน์ที่เลือก (running total) = 0
n(A∪B) ตามสูตรมาตรฐาน = 0
⭕แผนภาพเวนน์
🔢จำนวนสมาชิกที่กำหนดให้
🎛️กดปุ่มตามพจน์ของสูตร (กดลำดับใดก็ได้)
n(A∪B∪C) = |A| + |B| + |C| − |A∩B| − |A∩C| − |B∩C| + |A∩B∩C|
ผลรวมจากพจน์ที่เลือก (running total) = 0
n(A∪B∪C) ตามสูตรมาตรฐาน = 0
⭕แผนภาพเวนน์
