# 2. ให้ค่าใน data-th / data-en เป็น HTML แทนที่จะเป็นข้อความล้วน

วันที่: 2026-09-05

## สถานะ

ตกลงแล้ว

## บริบท

ทุกสื่อในโปรเจกต์สลับภาษาไทย/อังกฤษด้วยแพทเทิร์นเดียวกัน:

```js
document.querySelectorAll('[data-th]').forEach(el => { el.textContent = ... });
```

`textContent` ทำให้ค่าที่ใส่กลายเป็นตัวหนังสือล้วนเสมอ ผลคือ **ใส่มาร์กอัปลงใน `data-th` ไม่ได้เลย**
ถ้าใส่ `<span class="frac">…</span>` แท็กจะโผล่ให้ผู้ใช้เห็นเป็นตัวอักษร

ข้อกำหนดใหม่คือเศษส่วนทุกจุดต้องเป็นแบบบน/ล่าง ซึ่งต้องใช้มาร์กอัป `.frac` —
และเศษส่วนจำนวนมากอยู่ในประโยคที่ต้องแปลภาษา จึงหนีไม่พ้นต้องอยู่ใน `data-th`

ทางเลือกอีกทางคือรื้อมาร์กอัป: แยกข้อความไทยออกเป็น `<span data-th>` เล็กๆ แล้ววางสูตรไว้ข้างนอก
เป็นพี่น้องกัน (แพทเทิร์นที่ `definition-rules.html` ใช้อยู่บางจุด)

## การตัดสินใจ

เปลี่ยน `applyLang()` ในไฟล์แคลคูลัสทุกไฟล์จาก `textContent` เป็น `innerHTML`
และถือว่า **ค่าใน `data-th` / `data-en` เป็น HTML** นับจากนี้

ตรวจแล้วว่าปัจจุบันไม่มีค่าใดในไฟล์แคลคูลัสที่มี `&lt;` `&gt;` `&amp;` จึงเปลี่ยนได้โดยผลลัพธ์ไม่เปลี่ยน

## ผลที่ตามมา

- ใส่เศษส่วน ตัวยก ตัวห้อย และเน้นข้อความในประโยคที่แปลภาษาได้แล้ว
- **แลกมาด้วย**: ถ้าจะเขียนเครื่องหมาย `<` `>` `&` ในคำอธิบายต่อไปนี้
  ต้อง escape เป็น `&amp;lt;` `&amp;gt;` `&amp;amp;` (escape สองชั้น เพราะอยู่ในแอตทริบิวต์)
  ไม่งั้นข้อความจะหาย — จุดนี้พลาดง่ายและไม่มีอะไรเตือน
- เนื้อหาทั้งหมดเป็นข้อความคงที่ที่เราเขียนเอง ไม่มีอินพุตจากผู้ใช้เข้ามาทางนี้ จึงไม่มีประเด็นความปลอดภัย
- ถ้าเลือกทางรื้อมาร์กอัปแทน จะไม่มีข้อแลกนี้ แต่ต้องแก้มาร์กอัปหลายร้อยจุดและอ่านยากขึ้นมาก
